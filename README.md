# ツヅキ (TSUZUKI) — 開いた瞬間、続きから。

「読みたい」を意志ではなく**仕組み**で「使える知識」に変え続ける、社会人のためのビジネス書アプリ。

読む単位は一冊ではなく **1論点(1〜2分)**。読んだら30秒で「明日どう使うか」を自分の言葉で1行書き、**知識資産**として積み上がる。コアループは開いてから閉じるまで**3分以内**。

## なぜ社会人はビジネス書を読みきれないのか

1. **起動コスト** — 本を開く瞬間、一冊の総重量を先払いで見積もって怯む。スマホからの切り替えコストと「何を読むか」の選択コストが重なる。
2. **脳が移行の途中** — 行動制御が「意志の目的志向ループ(前頭前野)」から「自動の習慣ループ(基底核)」へ移譲される前に脱落する。疲労下では、自動化済みのスマホに必ず負ける。
3. **「気になる」の過剰** — 読みたい本は湧き続けるが、ブックマークで完結してしまい「今読む」への橋がない。

ツヅキは、この3層すべてを意志力ではなく設計で解く。

## 行動科学 → 機能マッピング

| 原理 | 実装 |
|---|---|
| デフォルト効果・選択過負荷の排除 | ホームは巨大な「続きを読む」ボタン1つ。次の1論点はアプリが事前決定 |
| 授かり進捗効果(Nunes & Drèze) | 各書籍は「論点0(30秒)」から始まり、進捗が0%から始まらない |
| 目標勾配効果 | 総ページ・全体進捗は見せない。「この章あと2論点」の近距離ゴールのみ |
| ツァイガルニク効果 | 読了画面で必ず次論点の予告(クリフハンガー)を見せてから閉じさせる |
| 実行意図 if-then(Gollwitzer) | 「電車に座ったら、ツヅキを開く」を本人が宣言。ホームに常時表示 |
| ピーク・エンドの法則 | 最後に山: カード生成演出+ランダム称賛(変動報酬)+予告 |
| 生成効果・検索練習 | 「明日どう使う?」を自分の言葉で1行。数日後に「これ、使った?」と再提示 |
| 週リズム(ストリーク廃止) | 連続日数ではなく「今週◯/3回」。1日の中断が全崩壊しない |
| フレッシュスタート効果(Milkman) | 月曜・月初・復帰時に「先週のことは関係ない」バナー。失敗履歴は表示しない |
| 罪悪感なきリカバリー | 7日以上空いたら「おかえり」。未読の蓄積数は絶対に見せない |
| アイデンティティベースの習慣 | カードの蓄積を「知識資産」として可視化。「今月◯論点を自分の言葉にした」 |
| 「気になる」の受け皿と橋 | 積読インボックスに3秒キャプチャ。燃焼中は常に1冊、読了で自動昇格 |

## 画面構成

- `/onboarding` — 共感 → if-then宣言 → **その場で論点0を読了**(インストールから90秒で最初の知識カードが完成)
- `/` — ホーム。「続きを読む」/週リズム/おかえり・フレッシュスタート/カード再提示
- `/read` — リーダー。1論点 → 1行アウトプット → 完了演出+クリフハンガー
- `/inbox` — 積読インボックス。かんたん追加(3秒キャプチャ)/ ISBNで正確に登録(書誌情報の自動取得+目次インポート)・キュー・自動昇格
- `/cards` — 知識資産。カード一覧と月間サマリー
- `/settings` — 合図・週目標の変更、データ初期化

## 技術構成

- **Next.js (App Router) + TypeScript + Tailwind CSS 4**
- 永続化は **localStorage**(`src/lib/store.tsx` に集約。将来のバックエンド差し替えを想定)
- 認証なし・クライアント完結。モバイルファースト + PWA manifest
- 収録コンテンツはツヅキ編集部による書き下ろしオリジナル論点(3冊×9論点)

### 実物の本の情報インポート

著作権上、他社の書籍本文は扱えない。そのためツヅキは「本文の代わりに、実際の目次に沿って読み進める進行表」を提供する。

- **ISBNで正確に登録**(`/inbox`): 本の裏表紙のISBNを入力すると、`src/app/api/isbn/route.ts` がサーバー側で [openBD](https://openbd.jp/)(日本の公開書誌データベース)を呼び出し、表記ゆれのない正しいタイトル・著者・出版社を取得する。openBDはCORS非対応のため、クライアントから直接は呼べず、このAPI Routeで中継している
- **目次貼り付け**: ISBN確認後、本の目次を1行1見出しで貼り付けると、`src/lib/seed.ts` の `buildCompanionUnits()` がその本専用の章立てで「1見出し・約5分」の読書セッションを自動生成する(第1章第1見出し→…と、実際の目次の言葉がそのままリーダーの論点タイトルになる)。空欄の場合は汎用の12回構成にフォールバックする
- **かんたん追加**: タイトルだけの3秒キャプチャも引き続き可能(屈辱的に低い入口を維持するため必須ではない)

```
src/
  lib/
    types.ts    # ドメイン型
    seed.ts     # 書き下ろしコンテンツ+伴走セッション生成
    logic.ts    # 状態遷移とセレクタ(純関数)
    store.tsx   # localStorage ストア(React Context)
    praise.ts   # 称賛コピープール(変動報酬)
  app/
    page.tsx  onboarding/  read/  inbox/  cards/  settings/
  components/
    BottomNav.tsx  WeekDots.tsx
```
